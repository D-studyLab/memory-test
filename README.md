# 記憶力テスト（memory-test）

数字は何桁まで、場所は何手まで覚えられるか。3課題で記憶のスパンを測る。
完全ブラウザ内動作（送信なし・外部ライブラリゼロ）。`index.html` を開くだけ。

▶ https://d-studylab.com/memory-test/

---

## 3つの課題

| 課題 | 中身 | 元になっている心理学の課題 |
|---|---|---|
| ① 順唱 | 数字が1つずつ出る → 出た順に答える | 数唱スパン（forward digit span） |
| ② 逆唱 | 同じように出る → **逆から**答える | 逆唱スパン。ワーキングメモリの中核 |
| ③ 場所 | マスが順に光る → 同じ順にタップ | Corsi ブロック課題（視空間スパン） |

## 測り方：階段法（10問固定ではない）

- 長さ3から始める
- **正解したら1つ長く**、間違えたら1つ短く
- **同じ長さで2回落ちたら**その課題を終了
- だから**誰でも必ず最後は間違える**。そこがその人の限界

⚠ **落ち続けない人（メモを取る等）でも必ず終わるように、1課題あたり9回の上限**を入れてある。
これが無いと、正解し続けるかぎり永久に終わらない（実装当初これに気づかず、ブラウザで
自動プレイさせて発覚した）。

## 偏差値の出し方

素点 = 順唱×1.0 ＋ **逆唱×1.4** ＋ 場所×1.2 （逆唱を重く見る）

基準は「順唱7・逆唱5・場所5」を偏差値50に置いた。順唱7±2 は Miller (1956) の
古典的な指摘で、逆唱5前後・視空間5前後は一般的に言われる目安。
**全国調査ではないので、あくまでこのテストの採点モデルによる擬似値**（画面にも明記）。

上下は25〜80で頭打ちにしてある。

## 弱点の指摘

3課題の偏りから、次のような読み方を返す。

- 順唱は高いのに逆唱が3以上低い → 覚える力より「頭の中で並べ替える力」が弱い
- 場所だけ2以上高い → 場所法（覚えたいものを部屋の風景に置く記憶術）が向いている
- 言語系だけ2以上高い → 図より声に出すほうが残る

## テスト

```
node memory.test.js    # 32件（決定論／出題の性質／逆唱の正解／階段法／偏差値／称号）
```

階段法については「正解し続けても必ず終わる」「正解と誤答が混ざっても必ず終わる」
「上限・下限を割らない」「元の状態を書き換えない」を検査している。

## 構成

```

```
